# 새벽 3시 편의점

> 야간 알바 7일 — 사람이 아닌 것을 가려내세요

한국 편의점에서 야간 아르바이트를 하는 주인공이 7일 밤 동안 손님을 받으며, 손님 중에 섞인 **사람이 아닌 것(닮은 것)** 을 수칙과 단서로 가려내는 판별 호러 게임입니다.

현재는 **7일 회차를 끝까지 플레이할 수 있는 프로토타입**입니다. 7일차 정산 뒤 9개 엔딩 가운데 하나가 나옵니다. 3D 매장은 기본 도형으로 만들어져 있고, UI는 IMGUI(`OnGUI`)로 그립니다. 아트가 준비되면 해당 부분만 교체할 수 있게 구성했습니다.

## 개발 환경

| 항목 | 내용 |
| --- | --- |
| 엔진 | Unity 6 (`6000.6.5f1`) |
| 언어 | C# |
| 데이터 | JSON (`JsonUtility`) |
| 메인 씬 | `Assets/Scenes/Main.unity` |

## 실행 방법

1. Unity Hub에서 이 폴더를 프로젝트로 추가합니다. 에디터 버전은 `6000.6.5f1`을 사용합니다.
2. `Assets/Scenes/Main.unity`를 열고 Play를 누릅니다.
3. 씬이 없거나 다시 만들고 싶으면 메뉴에서 **Tools > Build Main Scene**을 실행합니다.

> `Library/` 폴더는 저장소에 포함되지 않습니다. 처음 열 때 Unity가 다시 생성하므로 시간이 조금 걸릴 수 있습니다.

## 게임 흐름

하루는 **브리핑 → 근무(시간대별 손님/이벤트) → 정산** 순서로 진행됩니다.

1. **브리핑**: 점장 메모, 라디오, 나레이션이 나옵니다. 오른쪽 위의 **[수칙 노트]** 를 읽어야 근무를 시작할 수 있습니다.
2. **근무**: 손님이 계산대 앞에 도착하면 관찰 패널에 외형, 구매 품목, 결제 수단, CCTV 정보가 표시됩니다.
   - `바코드 찍기`, `신분증 요청`으로 정보를 더 얻을 수 있습니다.
   - 신분증을 요청하면 관찰 패널에 신분증 내용이 나옵니다.
   - 전에 온 적 있는 단골에게는 `지난번에 뭐 사셨죠?`로 진짜인지 확인할 수 있고, 윤 간호사에게는 친절 행동(예: `따뜻한 캔커피 건네기`)을 할 수 있습니다. 둘 다 최종 선택이 아닙니다.
   - 오래 바라보면(3초) 숨은 단서가 보이고, 10초가 지나면 추가 대사나 연출(형광등 깜빡임 등)이 나옵니다.
   - 최종 선택: `계산해 주기` / `거절하고 내보내기` / `비상벨 누르기` (전화 이벤트는 `전화 받기` / `무시하기`)
3. **정산**: 기본 급여와 선택에 따른 증감, 잘못 판단한 손님의 **CCTV 리플레이**, 점장 문자, 단골 근황을 보여 줍니다. 퇴근하면 자동 저장됩니다.

**위험도**가 10에 닿으면 근무 중 배드 엔딩(게임 오버)이 나오고, 그날을 처음부터 다시 시작할 수 있습니다.

7일차 정산을 마치면 우선순위대로 엔딩 하나가 정해집니다: 영업 정지 → 괴물 점령 → 해고 → 수화기 너머 → 숨겨진 로맨스 → 점장 → 단골 → 해피 → 평범한 알바. 자세한 조건과 회차 규칙은 [`Docs/RULES.md`](Docs/RULES.md)에 있습니다.

### 1일차 구성

1일차는 고정입니다. 손님은 6명입니다.

| 시간 | 이벤트 |
| --- | --- |
| 00:20 | 박 대리 (`D1_01_park`) |
| 00:50 | 손님 (`D1_02_student`, 미성년자) |
| 01:30 | 윤 간호사 (`D1_03_yoon`) |
| 02:40 | 전화 (`D1_E1_call`) |
| 03:00 | 손님 (`D1_04_drunk`, 함정) |
| 04:30 | 최 기사님 (`D1_05_choi`) |
| 05:10 | 손님 (`D1_06_shadow`, 닮은 것) |

예전 1일차 일반 손님(`D1_N01_coffee`, `D1_N02_ramyun`, `D1_N03_parcel`)은 2일차부터 일반 NPC의 대사 변형으로 나옵니다.

### 2~7일차

매일 손님 6명과 전화 1통이 무작위로 나옵니다. 새로 시작할 때 `RunPlanner`가 7일치 배치를 한 번에 정해 저장 파일에 넣습니다. 나오는 NPC도, 각 NPC의 대사 변형도 무작위이고, 회차 최소 등장(괴물 4, 미성년자 2, 수상한 전화 2, 윤 간호사 4, 박 대리 2, 최 기사님 2, 5일차부터 CCTV에 비치지 않는 괴물 1), 난이도 표, 위장 단골 규칙을 지킵니다. 매일 수칙이 하나씩 늘어납니다(R02~R09).

1일차 수칙

- 미성년자에게 술·담배를 팔지 말 것.
- 형광등 아래에서 그림자가 없는 손님에게는 아무것도 팔지 말고, 비상벨을 누를 것.
- (숨은 수칙) 문이 열릴 때 차임 소리가 나지 않는 손님은 사람이 아니다.

## 콘텐츠 추가하기

새 날짜나 손님은 **JSON 파일을 추가하는 것만으로** 늘릴 수 있습니다. 코드를 고칠 필요는 없습니다.

- **이벤트** (`Resources/Data/events/*.json`): ID 규칙은 `D{날}_{순번}_{이름}`입니다.
  - `type`: `normal` / `regular` / `trap` / `mimic` / `disguise` / `event` / `briefing` / `settle`
  - `npc`: 이 대사 변형의 주인 NPC (`Data/npcs`). 2~7일차 무작위 배치는 이 값으로 NPC를 묶습니다. NPC마다 변형이 3개 이상 있어야 합니다.
  - `trap` / `minor` / `suspicious`: 함정 손님 / 미성년자 / 받으면 안 되는 전화. `items[].restricted`는 술·담배입니다.
  - `kindness`: 친절 행동 버튼 (윤 간호사). `dialogue.ask_last`: 위장 단골이 `지난번에 뭐 사셨죠?`에 하는 오답 (진짜 단골은 비워 두면 실제 지난 구매로 대답합니다).
  - `condition.day` / `condition.day_max`: 무작위 배치에서 이 변형이 나올 수 있는 날
  - 플래그에 `{day}`를 쓰면 그 날 번호로 바뀝니다 (예: `D{day}_police_called`).
  - `truth`: `human` / `mimic` / `none`. 정산 리플레이의 정답 판정에 쓰입니다.
  - `clues[].visibility`: 1(숨은 단서, 3초 응시 후 표시) ~ 3(아주 분명)
  - `outcomes.{sell,refuse,alarm,answer,ignore}`: 급여·위험도 증감, 플래그, 다음 날 후속 이벤트
  - `appearance.fx`: 3D 연출 플래그 (`no_shadow`, `no_door_chime`, `no_cctv`, `light_sway`, `phone_ring`)
- **날짜** (`Resources/Data/days/dayN.json`): 시간대별 슬롯을 정합니다. `fixed`는 특정 이벤트를 고정하고, `pool: "customer"` / `pool: "phone"`은 회차 배치에서 손님·전화를 꺼냅니다. 그 밖의 `pool`과 `tags`는 조건에 맞는 이벤트 중 하나를 무작위로 고릅니다. `difficulty`의 `mimics`/`mimics_max`, `traps`/`traps_max`는 범위, `clue_visibility`는 그 날 단서 표시의 상한입니다.
- **수칙** (`Resources/Data/rules/*.json`): `day` 이후부터 수칙 노트에 표시되고, `hidden: true`인 수칙은 노트에 나오지 않습니다.

데이터를 추가한 뒤에는 **Tools > Check Data**로 스키마와 손님 수를 확인하세요. 회차 배치 2,000개를 만들어 규칙 위반과 엔딩 도달 가능성도 같이 검사합니다.

## 에디터 도구

| 메뉴 | 배치 모드 | 설명 |
| --- | --- | --- |
| Tools > Build Main Scene | `-executeMethod SceneBuilder.Build` | 3D 매장 씬 생성 |
| Tools > Check Data | `-executeMethod DataCheck.Run` | JSON 데이터 검증 + 회차 시뮬레이션 |
| Tools > Check Runs | `-executeMethod DataCheck.Runs` | 회차 시뮬레이션만 |
| Tools > Snapshot Counter View | `-executeMethod Snapshot.Run` | 계산대 시점 캡처 (그래픽 장치 필요) |

## 저장

진행 상황은 `Application.persistentDataPath/save.json`에 저장됩니다. 하루를 시작할 때와 퇴근할 때 자동으로 저장되고, 타이틀 화면의 **이어하기**로 불러올 수 있습니다.
