# 소품 모델 출처

모두 Poly Haven (https://polyhaven.com) 의 CC0 모델이다 (출처 표기 의무 없음, 상업적 사용 가능). 1k FBX 판.

| 폴더 | 쓰는 곳 |
|---|---|
| security_camera_01 | 계산대 뒤 왼쪽 위 CCTV |
| korean_fire_extinguisher_01 | 계산대 오른쪽 끝 뒤 소화기 |
| WetFloorSign_01 | 온수기 앞 미끄럼 주의 표지판 |
| plastic_crate_01 | 왼쪽 안쪽 구석 우유 상자 |
| cardboard_box_01 | 왼쪽 안쪽 구석 골판지 상자 |
| plastic_monobloc_chair_01 | 계산대 뒤 점원 의자 |

폴더에는 FBX 와 색(_diff)·노멀(_nor_gl) 맵만 넣었다. 소화기 라벨(_paper_diff)은 원본 색 맵에 opacity 맵을 알파로 합친 것이다.
재질(.mat)은 StoreProps.cs 가 장면을 만들 때마다 다시 만든다.
